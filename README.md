## Build System

The project uses **CMake** as the build system with configuration defined in `CMakeLists.txt`.

### Building the Project

1. Create a build directory:
   ```bash
   mkdir build
   cd build
   ```

2. Run CMake:
   ```bash
   cmake ..
   ```

3. Build the project:
   ```bash
   make
   ```
